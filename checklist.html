Website Launch Checklist

Use this checklist to ensure your new site is secure, fast, and ready for traffic.

Performance & Speed

Images Optimized

Compress all images (WebP format preferred) and use lazy loading.

Mobile Responsive

Test on multiple devices (iPhone, Android, Tablet) to ensure layout holds up.

Core Web Vitals

Run a Lighthouse audit. Aim for green scores in Performance, Accessibility, and SEO.

SEO & Visibility

Meta Tags

Every page has a unique Title and Description. Open Graph tags for social sharing.

Sitemap & Robots.txt

Submit sitemap.xml to Google Search Console. Ensure robots.txt isn't blocking crawlers.

Analytics Installed

Google Analytics or Plausible is tracking page views and events correctly.

Security & Trust

SSL Certificate

HTTPS is active and enforced. No mixed content warnings.

Privacy Policy

Privacy policy page is live and linked in the footer. Cookie consent if required.

Backups Configured

Automated backups are running (daily/weekly) and stored off-site.
